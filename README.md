# VUM CRM Platform Repository

This repository contains the VUM CRM Platform source code.

## Subdirectories

- **`crm-fe/`**: VUM CRM React Single Page Application Frontend Foundation. Refer to [`crm-fe/README.md`](./crm-fe/README.md) for installation, running, and test instructions.
- **`crm/`**: Java Maven Backend project directory.
- **`docs/`**: Schema definition files:
  - `crm_mysql80.sql` (Base CRM MySQL 8.0 schema)
  - `crm_mysql80_auth.sql` (Authentication extension schema)
